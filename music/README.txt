🎵 THƯ MỤC NHẠC NỀN
========================

Đặt file nhạc vào đây, đặt tên là:

  background.mp3   ← tên này sẽ tự động load khi mở thiệp

Hoặc bất kỳ tên nào bạn muốn:
  nhac_nen.mp3
  ky_yeu.mp3
  ...

Định dạng hỗ trợ: .mp3 / .ogg / .wav / .m4a

💡 Gợi ý nhạc phù hợp cho kỷ yếu:
   - Nhạc nhẹ, không lời (instrumental)
   - Nhạc acoustic guitar
   - Piano cover các bài nhạc trẻ
   - Thời lượng: 3-5 phút (có loop tự động)

⚠️  Sau khi đặt file nhạc xong, báo lại để cập nhật code tự động đọc!
